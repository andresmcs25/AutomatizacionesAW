# Archivos de trabajo

Coloca aquí los archivos locales que usan los procesos. Los libros Excel y archivos CSV de esta carpeta están excluidos de Git para evitar publicar datos de trabajo.

- `Cartera/`: insumos de cartera.
- `SGA/`: exportaciones CSV de SGA.
- `CarguePagos/`, `FT037/` y `MOV_PAGOS/`: carpetas conservadas para organizar esos procesos más adelante.

Al clonar el repositorio, la app crea las carpetas `Cartera` y `SGA` si hacen falta. Copia tus archivos de trabajo manualmente; no se versionan.
